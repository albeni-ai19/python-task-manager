# Python Task Manager

## Описание проекта
Консольное приложение на Python для управления списком задач. Проект разработан для демонстрации навыков работы с ветками Git, параллельной разработки, слияния (Merge) и перебазирования (Rebase).

## Возможности
* Добавление новых задач.
* Вывод списка всех задач.
* Отметка задачи как выполненной.
* Удаление задачи.
* Поиск и фильтрация задач.
* Валидация пользовательского ввода.

## Используемые технологии
* Python 3
* Git / GitHub

## Структура проекта
* `src/` — каталог с исходным кодом (`main.py`, `search.py`)
* `tests/` — каталог для модульного тестирования (`test_main.py`)
* `README.md` — основная документация
* `requirements.txt` — зависимости проекта

## Требования
* Python 3 и Git
